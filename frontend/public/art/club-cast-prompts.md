# Animated club cast

The built-in Image Gen tool generated three original transparent 1086 × 1448 PNG portraits, saved as:

- `dancer-rose.png`
- `dancer-mint.png`
- `dancer-violet.png`

The trombinoscope reuses these portraits, the existing nightclub panorama and the DJ cat. Whole character images dance with offset CSS transforms; the chart data layer is not transformed. All human characters are adults. The cast is decorative artwork, not online users or a live video feed.

Each final generation prompt concatenates this prefix, one character description, and the suffix below.
